# Personal Portfolio Website

A clean, modern, and responsive personal portfolio website built with **HTML5 and CSS3**.  
The website is designed to showcase personal information, services, selected projects, and contact details through a visually focused portfolio layout.

## ✨ Features

- Responsive portfolio layout
- Modern and clean visual design
- Hero section with personal introduction
- About Me section
- Services section
- Projects showcase
- Contact section
- Social media links
- Call-to-action buttons
- Custom typography using Google Fonts
- Responsive layouts for different screen sizes
- Mobile-friendly design

---

## 🛠️ Technologies Used

- **HTML5** — semantic structure and page content
- **CSS3** — layout, styling, responsiveness, and visual design
- **Google Fonts** — custom typography
- **Git** — version control
- **GitHub** — source code hosting and repository management
